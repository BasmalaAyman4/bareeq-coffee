# Bareeq

Bareeq's café website: menu, product pages, locations, a shopping bag, and a WhatsApp order review. It uses React and TypeScript and builds a static website. There is no database or payment server.

The opening animation plays automatically whenever the homepage is opened. Visitors who use reduced-motion settings will go straight to the site.

## Start editing

1. Open the `D:\bareeq` folder in your code editor.
2. Open a terminal in that folder.
3. On a fresh computer, install Node.js 22.13 or newer, then run `npm ci` once.
4. Run `npm run dev`.
5. Open http://127.0.0.1:5173 in your browser.

Saving a file in `src` or `public` rebuilds the website. Refresh the browser after the terminal says Ready. Stop the server with Ctrl+C. If the port is occupied, PowerShell users can run `$env:PORT=5174` before starting it.

## Where to make changes

- **Product names, prices, images, availability:** `src/data/products.json`.
- **Café contact details, currency, map:** `src/data/site.json`.
- **Home page and hero:** `src/pages/home.tsx`.
- **Menu search and category filters:** `src/pages/menu.tsx`.
- **Individual product page:** `src/pages/product.tsx`.
- **Shopping bag and checkout:** `src/pages/cart.tsx`.
- **Location page:** `src/pages/locations.tsx`.
- **Header, navigation, footer:** `src/components/shell.tsx`.
- **Saved cart, quantities, storage:** `src/components/cart-provider.tsx`.
- **Product cards, quantity buttons, price formatting:** `src/components/products.tsx`.
- **Intro animation:** `src/components/loader.tsx`.
- **Colors, fonts, spacing, mobile styles:** `src/styles/globals.css`. Brand colors are at the top.
- **Photos and logos:** `public/assets`. Reference them as `/assets/filename.webp`.

## Project structure

```text
bareeq/
  src/
    pages/          Each screen has its own file
    components/     Shared pieces used by multiple screens
      ui/           Shared button
    data/           Editable product and café information
    styles/         Website CSS
    lib/            Small shared helpers
    app.tsx         Chooses which page to show
    routes.ts       Page titles
    router.tsx      Local navigation
    client.tsx      Starts the app in the browser
    server.tsx      Generates the initial HTML during a build
  public/assets/    Website images
  scripts/          Build and local preview commands
  .openai/          Existing hosting connection; preserve it
  .git/             Git metadata; preserve it
  package.json      Commands and dependencies
  package-lock.json Exact dependency versions; keep this file
  README.md         This guide
```

`node_modules` contains installed dependencies. Never edit it; `npm ci` recreates it. `dist` is generated by `npm run build`. Never edit `dist`; changes there are overwritten.

## Common edits

### Change a product

Find the product in `src/data/products.json`. Change its name, price, description or image. Keep its `id` stable so saved shopping bags still work. Keep `slug` unique; it forms the product URL. A `null` price means the café must confirm the price. Keep `available` as `true` or `false`, without quotes.

To add a product, copy an existing product object, assign a new unique `id` and `slug`, and update its details. Use an existing category so it appears in the menu filters. Images belong in `public/assets`.

### Add a page

Create the component in `src/pages`, add its route to the switch in `src/app.tsx`, and add its title in `src/routes.ts`. Add a navigation link in `src/components/shell.tsx` if needed. The build generates all routes listed in `src/routes.ts`, plus all product pages.

### Keep code readable

Use descriptive names and small components. Keep editable content in `src/data` when several pages share it. Run `npm run format` after edits to apply consistent indentation. Use `npm run typecheck` to catch TypeScript errors.

## Commands

- `npm run dev`: build, preview, and rebuild when source files change.
- `npm run build`: generate the complete static website in `dist`.
- `npm start`: preview an already built `dist` folder.
- `npm run typecheck`: check TypeScript.
- `npm run format`: format source, scripts, and documentation.
- `npm run format:check`: check formatting without changing files.

Before publishing, run typecheck, format:check, and build. Existing Sites hosting uses `dist`, configured in `.openai/hosting.json`. This cleanup does not publish changes.

## How orders work

The shopping bag is saved in the visitor's browser. Checkout prepares a WhatsApp message for the visitor to review and send. The café confirms availability and the final total. No payment is collected by this website.
